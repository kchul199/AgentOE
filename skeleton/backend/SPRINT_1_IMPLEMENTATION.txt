WEBSOCKET PROTOCOL SUMMARY
────────────────────────────
  Connection: ws://host/api/v1/ws/vbgw?token=<JWT>&session_id=<UUID>

  Client → Server:
    binary                          PCM 오디오 (8kHz, 16-bit mono)
    {"action":"start_listening"}    발화 시작
    {"action":"stop_listening"}     발화 종료 (잔여 버퍼 플러시)
    {"action":"hangup"}             통화 종료
    {"action":"ping"}               keepalive

  Server → Client:
    {"event":"connected",     "session_id":"..."}
    {"event":"state_change",  "state":"LISTENING"}
    {"event":"stt_result",    "text":"...", "is_final":true}
    {"event":"llm_chunk",     "text":"...", "is_final":true, "is_filler":false}
    {"event":"tts_ready",     "audio_b64":"<base64>", "text":"..."}
    {"event":"pipeline_done", "latency":{...}, "policy_level":"G1"}
    {"event":"error",         "code":"...", "message":"..."}
    {"event":"pong"}

  Close Codes:
    4001 — Invalid/expired JWT
    4003 — Tenant kill switch active
